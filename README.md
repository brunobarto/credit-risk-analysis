# credit-risk-analysis

The charts and the font load from a CDN, so you need an internet connection.

The page has six sections:

Financial ratio analysis: a radar chart comparing healthy and defaulted borrowers, plus a table of the actual ratio values.
Credit score distribution and default rate: the number of borrowers in each score band, with the default rate for each band.
Default-risk prediction: a live simulator. Move the sliders to get a score, a default probability, a decision and a list of what lowered the score.
Customer segmentation: four borrower groups plotted by credit score and debt-to-income ratio.
Model performance: an ROC curve, feature importance and a confusion matrix.
Business insights: four findings with the numbers behind them.
Every chart has an ⓘ button. It opens a pop-up window that explains what the chart shows, how to read it and what it means for the business. The pop-ups switch between English and French along with the rest of the page.


To present it, open with the KPI row and the score distribution chart, which shows default rate falling as scores rise. Then score an applicant live in the simulator, and end on the insights cards. Every number is made up but kept realistic: about a 4.7% default rate, AUC 0.87, Gini 0.74 and a 300–850 score range. The footer says the data is synthetic.
